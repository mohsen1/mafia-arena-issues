# Mafia Arena Issues

This repository is dedicated to tracking issues, bugs, and feature requests for [mafia-arena.com](https://mafia-arena.com).

## Purpose

This is an **issues-only repository**. It does not contain any source code. All development for Mafia Arena happens in a private repository.

## How to Report an Issue

If you've encountered a bug or have a feature request for Mafia Arena, please:

1. Check if a similar issue already exists
2. Click on the "Issues" tab above
3. Click "New Issue"
4. Choose the appropriate template (Bug Report or Feature Request)
5. Fill in the required information
6. Submit the issue

## Guidelines

- Be respectful and constructive in your feedback
- Provide as much detail as possible when reporting bugs
- Include steps to reproduce the issue
- Mention your browser and device information when relevant

## Not Sure Where to Start?

- **Found a bug?** → [Report a bug](../../issues/new?template=bug_report.md)
- **Have an idea?** → [Request a feature](../../issues/new?template=feature_request.md)
- **Need help?** → Check existing issues or create a new one
