# Contributing to Mafia Arena

Thank you for your interest in contributing to Mafia Arena!

## Important Notice

**This repository is for issue tracking only.** It does not contain source code for Mafia Arena. All development happens in a private repository.

## How You Can Contribute

### Report Bugs
If you find a bug in Mafia Arena:
1. Search existing issues to avoid duplicates
2. Use the [Bug Report template](../../issues/new?template=bug_report.md)
3. Provide detailed information about the bug
4. Include steps to reproduce the issue

### Suggest Features
Have an idea to improve Mafia Arena?
1. Check if someone else has already suggested it
2. Use the [Feature Request template](../../issues/new?template=feature_request.md)
3. Explain why this feature would be valuable
4. Describe how it might work

### Participate in Discussions
- Comment on existing issues to provide additional information
- Vote on feature requests using 👍 reactions
- Help other users by sharing your experiences

## What We Cannot Accept

- **Pull Requests**: Since this is an issues-only repository with no source code, we cannot accept PRs
- **Code Contributions**: Development happens in a private repository
- **Direct Code Fixes**: Please report bugs instead, and the development team will address them

## Issue Guidelines

### Be Respectful
- Treat everyone with respect and courtesy
- Keep discussions constructive and on-topic
- Avoid spam or off-topic comments

### Be Clear
- Use descriptive titles for your issues
- Provide as much relevant detail as possible
- Use proper formatting to make your issue easy to read

### Be Patient
- The development team will review issues as time permits
- Not all feature requests can be implemented
- Bug fixes are prioritized based on severity and impact

## Questions?

If you have questions about the game or need help, please:
- Check if your question has already been answered in existing issues
- Create a new issue with a clear, descriptive title
- Provide context about what you're trying to do

---

Thank you for helping make Mafia Arena better! 🎮
